# Fernando Hocevar - Portfolio

Site estático de portfólio técnico para publicação no GitHub Pages.

## Estrutura

```txt
fernando-portfolio/
├── index.html
├── style.css
└── images/
```

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo:
   `fernando-portfolio`

2. Envie estes arquivos para o repositório.

3. No GitHub, acesse:

```txt
Settings → Pages → Deploy from branch → main → root → Save
```

4. O GitHub vai gerar uma URL parecida com:

```txt
https://seu-usuario.github.io/fernando-portfolio/
```

## Pontos para ajustar

- Trocar o link do GitHub no `index.html`
- Trocar `mailto:seuemail@exemplo.com`
- Substituir os cards visuais por prints reais dos projetos
- Adicionar links reais dos repositórios
